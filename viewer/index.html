会社に接続する

会社リポジトリ（GitHub）と、そのリポジトリ専用のトークンを入力してください。トークンはこのブラウザの中にだけ保存されます。

詳細設定（通常は不要です）

トークンの作り方：GitHub の Settings → Developer settings → Personal access tokens → Fine-grained tokens で、対象の会社リポジトリだけを選び、Repository permissions の Issues と Contents を Read and write にします。PC ごとにトークンを分けると、不要になった PC の分だけを消せて安全です。
